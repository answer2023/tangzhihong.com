网页翻译

原文在上，译文在下。

读研报、看外媒、查资料时，最怕来回切换。双语对照把译文放在每一段原文下面，一眼对照，不丢上下文。

  • 标题、段落、列表、引用逐段翻译，导航栏逐项翻
  • 只翻你看得到的部分，长页面不卡；后加载的内容自动跟上
  • 代码块、输入框、本来就是中文的段落自动跳过
仅显示译文

一键切换，整页变中文。

不想看原文时，切到「仅显示译文」：页面排版保持原样，链接照常能点，浏览器标签页标题也一并翻译。

  • 双语 ⇄ 仅译文随时切换，不重复请求，不多花一分钱
  • 快捷键 ⌥ A、右键菜单、工具栏图标都能触发
  • 常看的网站可设为「总是翻译」，打开即译
视频双语字幕

打开字幕，就是双语。

在 YouTube 打开视频，插件自动开启字幕并换成中英双语：原文在上，黄色译文在下。直播也能用。

  • 自动生成的字幕先按句断开再翻，不再一个词一个词地跳
  • 优先翻译当前播放位置，拖动进度条也能马上跟上
  • 直播边播边翻：实时读取直播字幕，一句话说完就出译文
  • 原文、译文字号分开调；全屏时字幕不突然变大
  • 视频本身没有字幕时会提示你，不用干等
翻译引擎

用你自己的大模型。

零配置就能用：微软、谷歌两个免费翻译引擎互为备份，国内通常不用代理。填上 API Key 后交给大模型：栏目名会意译，专有名词带书名号，术语更准。

  • 预设 DeepSeek、通义千问、Kimi、智谱 GLM、OpenAI、OpenRouter
  • 任何 OpenAI 兼容接口都能接
  • 智能模式：大模型出错自动退回免费翻译，免费翻译也会自动换引擎，不会卡在半路
隐私

不常驻，不收集，不上传。

01

按需访问网页

插件平时不读取任何网页。只有你点图标、按快捷键或用右键菜单时，才临时访问当前这一个标签页。

02

没有自己的服务器

要翻译的文字只发给你选的翻译服务。不收集浏览记录，没有广告，没有统计代码。

03

Key 只在你的电脑上

API Key 保存在本机浏览器的 storage.local 里，不同步、不上传，只在调用你选的服务商时使用。

怎么用

三步上手。

STEP 1

安装插件

上架后从 Chrome 应用商店一键安装。点工具栏的拼图图标，把 ClearSky 固定出来。

STEP 2

翻译网页

点插件图标 →「翻译此页面」，或者按 ⌥ A。再按一次恢复原文。

STEP 3

看视频

打开任意 YouTube 视频，双语字幕会自动出现。想要更好的译文，在设置页填上大模型 Key。
