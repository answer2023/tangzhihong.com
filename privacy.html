隐私政策

生效日期：2026-11-10 开发者：ClearSky

本政策适用于 tangzhihong.com（含其 GitHub Pages 部署域名）上的静态网站内容。开发者署名为 ClearSky。如有疑问，请联系 hi@tangzhihong.com。

本站是什么

本站是 ClearSky 独立工作室的静态产品介绍页：介绍产品、更新动态与博客文章。页面由静态 HTML / CSS / JavaScript 构成，通过 GitHub Pages 托管。

本站不提供账号注册、登录、支付或表单收集，也不运营自有后端来收集或存储你的个人信息。

我们收集什么

就本站本身而言：我们不主动收集姓名、邮箱、电话、位置、浏览历史等个人信息，也未嵌入广告、分析统计或用户追踪脚本（例如常见的第三方 analytics）。

你通过页脚「Email」或本页联系邮箱主动发来的邮件，仅用于回复你的问题；邮件由你使用的邮箱服务商按各自政策处理。

第三方资源（页面加载时）

为渲染页面，本站会从公开 CDN 加载必要的前端资源。浏览器向这些服务发起请求时，可能附带常规网络元数据（如 IP、User-Agent），处理方式适用对方政策：

  • unpkg.com：加载 React / ReactDOM 运行时脚本；
  • fonts.googleapis.com：加载站点所用的 Noto Sans SC 字体样式。

除此以外，本站不额外引入统计或追踪类第三方脚本。

各产品的隐私政策

具体 App / 插件如何处理你的数据，以各自产品的隐私政策为准（本站只做介绍与入口）：

  • JotBee 隐私政策
  • VoiceBee 隐私政策
  • ClearSky 双语翻译 隐私政策

其它在本站展示、但尚未单独发布公开隐私页的产品，不适用本站政策之外的额外承诺；使用前请以该产品界面与文档说明为准。

儿童隐私

本站为产品介绍站，不面向 14 岁以下儿童收集个人信息，也不向儿童定向投放广告。

政策变更

若本政策更新，将在本页面公布并修订生效日期。
